# Debatify

## AI-Powered Debate Coach

Debatify is an AI-powered debate coaching application that analyzes spoken or written arguments and provides structured feedback to help users improve their reasoning, clarity, evidence, and ability to respond to counterarguments.

The backend is built using Flask and integrates Google's Gemini API for argument analysis and improvement. It also uses Google Speech Recognition to convert spoken arguments into text.

## Features

* Speech-to-text conversion for spoken debate arguments
* AI-powered argument evaluation
* Rationality scoring from 0 to 1
* Analysis of logical structure
* Evaluation of clarity and coherence
* Assessment of supporting evidence
* Identification of potential counterarguments
* Generation of concrete debate challenges
* AI-generated improved versions of arguments
* REST API endpoints for frontend integration
* Dynamic Gemini model selection

## API Endpoints

### 1. Home

```http
GET /
```

Returns a simple message confirming that the Debatify backend is running.

### 2. Speech-to-Text

```http
POST /speech-to-text
```

Converts an uploaded WAV audio file into text using Google Speech Recognition.

#### Request

Send the audio file using multipart form data with the field:

```text
file
```

#### Example Response

```json
{
    "transcription": "The argument provided by the speaker..."
}
```

#### Possible Errors

```json
{
    "error": "No file provided"
}
```

```json
{
    "error": "Could not understand audio"
}
```

### 3. Evaluate Argument

```http
POST /evaluate-argument
```

Analyzes a debate argument using Gemini.

#### Request Body

```json
{
    "topic": "Should artificial intelligence be regulated?",
    "text": "Artificial intelligence should be regulated because..."
}
```

#### Evaluation Criteria

The AI evaluates the argument based on:

* Logical structure
* Clarity and coherence
* Supporting evidence
* Potential counterarguments
* Rationality

The API also generates an improved version of the original argument while preserving its core ideas.

#### Example Response

```json
{
    "rationality_score": 0.8,
    "reason_for_score": "The argument follows a clear logical structure but could benefit from stronger supporting evidence.",
    "feedback": {
        "logical_structure": "...",
        "clarity": "...",
        "supporting_evidence": "...",
        "counterarguments": "..."
    },
    "improved_argument": "..."
}
```

## How the Argument Evaluation Works

The `/evaluate-argument` endpoint follows these steps:

```text
User Argument
      |
      v
Validate Topic and Argument
      |
      v
Construct AI Evaluation Prompt
      |
      v
Send Prompt to Gemini
      |
      v
Receive AI Analysis
      |
      v
Extract Rationality Score
      |
      v
Extract Feedback
      |
      v
Generate Improved Argument
      |
      v
Return JSON Response
```

The Gemini model is instructed to evaluate the argument across multiple dimensions and return a structured response. Regular expressions are then used to extract the relevant sections from the generated response.

## Rationality Score

Debatify assigns a rationality score between `0` and `1`.

| Score Range | General Interpretation              |
| ----------- | ----------------------------------- |
| 0.0 - 0.3   | Highly emotional or weakly reasoned |
| 0.4 - 0.6   | Moderately rational                 |
| 0.7 - 0.8   | Generally well-reasoned             |
| 0.9 - 1.0   | Highly rational                     |

The score is generated by the Gemini model based on the argument's reasoning and supporting content.

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/bhavanimish/Debatify.git
cd Debatify
```

### 2. Create a Virtual Environment

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

Linux/macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

If `requirements.txt` has not been created yet:

```bash
pip install flask speechrecognition python-dotenv google-generativeai
```

### 4. Configure the Gemini API Key

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Do not commit the `.env` file to GitHub.

Add the following to `.gitignore`:

```gitignore
.env
venv/
__pycache__/
*.pyc
```

### 5. Run the Application

```bash
python app.py
```

The Flask server will run on:

```text
http://localhost:5000
```

## Environment Variables

The application requires the following environment variable:

| Variable         | Description                                |
| ---------------- | ------------------------------------------ |
| `GEMINI_API_KEY` | API key used to access Google's Gemini API |
| `PORT`           | Optional port for running the Flask server |

If `PORT` is not provided, the application uses port `5000`.

## Error Handling

The backend handles several common errors, including:

* Missing audio files
* Audio that cannot be recognized
* Speech Recognition API failures
* Missing request parameters
* Gemini API errors
* Blocked or unavailable AI responses
* Missing Gemini API credentials

API errors are returned as JSON responses with an appropriate HTTP status code.

## Security Considerations

The Gemini API key is loaded from environment variables using `python-dotenv`. API keys should never be hardcoded into the source code or committed to the repository.

For production deployment, additional security measures should be considered, including:

* API authentication
* Request validation
* Rate limiting
* Secure file handling
* HTTPS
* Temporary file cleanup
* Production-grade Flask deployment
